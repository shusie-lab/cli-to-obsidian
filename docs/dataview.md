# 昨日と今日のAIチャットを振り返る

開発者が日々使っている[昨日と今日のAIチャット.md](../templates/dataview/昨日と今日のAIチャット.md)を、Dataviewの活用例として公開しています。昨日と今日にAIとどんな会話をしたかをざっと確認し、会話ノートへ戻ったり、日報に残す会話を探したりするための一覧です。

## 使い方

1. ObsidianでDataviewプラグインを有効にします。
2. 上のファイルリンクを開き、GitHubの **Download raw file** からダウンロードします。
3. Obsidian保管庫の好きな場所（例：`Dashboard/`）へ置いて開きます。

対象の保存先は`生成AI/ChatLog`です。`OBSIDIAN_OUTPUT_DIR`で保存先を変えている場合は、ファイル内の4か所の`FROM "生成AI/ChatLog"`を同じ保存先に変更してください。説明を毎回読まずに使えるよう、ダッシュボード本体には一覧だけを置いています。

## 一覧の見方

今日の一覧は更新日時の新しい順、昨日の一覧はUSD参考換算の多い順です。「会話」は元ノートへのリンク、「タイトル」は依頼内容、「発言数」は記録された発言の件数、「保存元」は保存フォルダの末尾の名前です。「参照」は、その会話ノートへリンクしているノート数を示します。

日付の判定にはノートの`modified`を使います。昨日始めた会話を今日再開して更新すると、今日の一覧へ移ります。日ごとの会話履歴を固定して保存するものではありません。

`$`は会話全体の累計USD参考換算、`総計$`はその日の一覧に該当する会話のうち、参考換算値があるものの合計です。**その日に使った金額や実際の請求額ではありません。** 金額を取得できない会話も一覧には表示しますが、総計には加算しません。未登録モデルなどが混在する「部分換算」の会話では、換算できた金額のみ含みます。表示は小数2桁に丸めるため、各行の表示額を足した値と総計に差が出る場合があります。

USD参考換算・発言数は作業時間を表すものではありません。金額の詳しい意味は[記録仕様](usage-spec.md)、保存先の設定は[共通設定](configuration.md)を参照してください。
